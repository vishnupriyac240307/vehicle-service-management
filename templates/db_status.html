STEP 1

Configure Oracle Credentials in .env

Open .env in your project directory and set your Oracle Database parameters:

ORACLE_USER=system
ORACLE_PASSWORD=your_oracle_password
ORACLE_HOST=localhost
ORACLE_PORT=1521
ORACLE_SERVICE_NAME=FREEPDB1   # or XEPDB1 / ORCLPDB1

PDB Reference:
• Oracle Database 23ai Free: FREEPDB1
• Oracle Database Express Edition (XE 18c/21c): XEPDB1
• Oracle Enterprise Edition: ORCLPDB1 or ORCLCDB

STEP 2

Execute Scripts in Oracle SQL Developer

Launch Oracle SQL Developer, connect to your Oracle database, and open the provided SQL scripts:

  1. All-In-One Execution:
    Open full_database_setup.sql and click Run Script (F5).
  2. Individual Script Sequence:
    a. Open schema.sql and press F5 (creates CUSTOMER, VEHICLE, SERVICE).
    b. Open sample_data.sql and press F5 (inserts initial data and issues COMMIT).
    c. Open queries.sql to test individual CRUD, filtering, aggregate, and JOIN operations.
STEP 3

Start the Flask Web Server

Activate your virtual environment and start the web dashboard:

# Start the Flask web application
python app.py

Navigate to http://127.0.0.1:5050 in your browser. All metrics and records will be fetched directly from Oracle Database!

DBA TIPS

Troubleshooting Common Oracle Errors

  • ORA-12541 (TNS:no listener): Oracle listener is not running. On Windows, start OracleOraDB21Home1TNSListener service or run lsnrctl start in command prompt.
  • ORA-01017 (invalid username/password): Check credentials in .env. In Oracle 12c+, common users in CDB require c## prefix, or connect directly to the Pluggable Database (PDB).
  • ORA-12514 (listener does not know service): Verify ORACLE_SERVICE_NAME in .env matches your active PDB (e.g. FREEPDB1 or XEPDB1). Run lsnrctl status to view registered services.
